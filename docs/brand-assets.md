# Bee Companion identity

The product uses an abstract folded ribbon, with no bee, insect, honeycomb, or mascot. The interface palette is indigo/periwinkle, warm neutral system surfaces, mint for completion, and muted amber for time and attention. System colors preserve dark-mode contrast and standard native controls remain in place.

The world-clock display uses hours and minutes only. Refresh cadence is once per minute.

Assets:
- `macos/Assets/AppIcon.png`: 1024px master.
- `macos/Assets/AppIcon.icns`: native multi-resolution application icon.
- `macos/Assets/AppIcon.iconset`: sizes from 16px to 1024px.
